RoughFeel optimizes high-performance data ingestion and real-time processing through scalable, auto-scaling architecture on multi-processor clusters.

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/RoughFeel.git`
2. `cd RoughFeel`
3. Install in editable mode: `pip install -e .`

## Configuration

RoughFeel is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
